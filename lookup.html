📌 座標補齊 — 用 Google Places 抓「還沒有座標」的地點

直接讀 data/*.json，把 lat 為空或 coord_status=missing 的地點丟給 Google Places， 取回官方座標、地址與營業時間。座標稽核｜地圖｜行程
⚠️ 計費 API，且只能從金鑰允許的網域開啟（localhost:5173）。 本頁讀的是 data/*.json 原始檔，只有本機 python -m http.server 5173 跑得起來， GitHub Pages 上不一定有 data 目錄。
和 verify.html 的差別：verify.html 是「已經有座標，拿 Google 比對距離」； 這一頁是「根本還沒有座標，跟 Google 要一個」。查詢字串優先用該筆的 q 欄位。 回傳的地址請逐筆看過——Google 是「用名字找店」，同名分店、或名字太通用（例如 artwork）時會配到別家。
